Submit and watch

The user asks a worker to edit a repository at a specific checkout. --watch streams task records plus harness text and tool calls until the task reaches a terminal state.

$ workctl task submit \
    --title "Add a JSON health check to widgetd" \
    --intent "In the widgetd service, add a /healthz endpoint that returns JSON with status and version, update tests, and leave a concise summary." \
    --repo git@git.sr.ht:~example/widgetd \
    --repo-name widgetd \
    --checkout main \
    --harness opencode-acp \
    --executor local-devshell \
    --watch

Inspect outputs, records, and artifacts

Outputs

Human-facing results, including summaries, are durable task outputs.

$ workctl task outputs 018f4f54-10c7-74c0-a9df-cc742a1d5f0b
out_01jz8pbr8k	Summary	Summary
